# Flutter Login Page

A polished Flutter login page with a modern authentication screen, email and password fields, and a mobile-first UI preview.

## Project Preview

![Project Preview](assets/images/login_icon.png)

## Overview

This repository contains a Flutter login screen project built for Android and iOS. It includes a branded login UI, custom form styling, and responsive layout design for mobile devices.

## Project Features

- Clean Flutter login page UI
- Email address field and password input
- Styled sign in and sign up buttons
- Responsive app preview for mobile screens
- Built with Flutter `material` widgets and `google_fonts`

## Installation

1. Install Flutter: https://flutter.dev/docs/get-started/install
2. Open the project folder in VS Code or Android Studio.
3. Run:

```bash
flutter pub get
flutter run
```

## Recommended Setup

- Flutter SDK `3.12.2` or later
- Android Studio or Visual Studio Code
- A connected Android/iOS device or emulator
